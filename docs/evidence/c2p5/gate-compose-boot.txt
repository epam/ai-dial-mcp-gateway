## Probe battery (liveness/trust/routing/end-to-end) — all green

The probes need a **slow allowlisted origin** for the liveness row (default allowlist is
`https://claude.ai`). As group 7 did, a temporary compose override added
`https://httpbin.org` for that one run, then the gateway was recreated from the committed
configuration and the allowlist verified back.

### probe_liveness (F1) — PASS

    python scripts/probe_liveness.py --slow-client-id https://httpbin.org/delay/5
    origin=http://localhost:8090 slow_client_id=https://httpbin.org/delay/5
    slow_origin_hold=5.0s
    control /healthz: samples=['0.2030s', '0.0000s', '0.0470s']
    [PASS] control: worst=0.2030s
    during the held-open leg: /healthz 200 in 0.0150s
    [PASS] healthz answers during a slow outbound leg: status=200 duration=0.0150s budget=2.0300s
    [INFO] the slow leg answered 400 in 11.91s (the fetch was held for ~5.0s)
    VERDICT: PASS                                              (exit 0)

The held-open leg genuinely held (11.91s) and `/healthz` answered in 0.0150s — the event
loop stayed free during a slow outbound fetch. Override removed after; the gateway
recreated from committed config, and `GATEWAY_CIMD_ALLOWED_ORIGINS` verified back at
`https://claude.ai`.

(Note: an initial liveness run without the override saw the slow leg refuse in 0.05s —
httpbin is not allowlisted by default, so the held-open leg was not exercised. That run
is not the gate; the overridden run above is.)
